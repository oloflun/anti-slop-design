# Design catalogue

The catalogue is a folder in the repo, not an app: `C:/Users/Anton L/anti-slop-design/design-catalogue/`.
Every reference is `entries/<slug>/entry.md` (YAML frontmatter + body) plus its images and, when a
live URL exists, `extract/` from `designlang`. `index.json` and `categories.json` are generated by
`scripts/catalogue/index.py` and never hand-edited. `sites/catalogue.html` (built by
`scripts/catalogue/build_page.py`) is the browsable page, served on Vercel as `/catalogue` and locally
with `python ~/.claude/skills/design/scripts/serve.py --port 4610 --root .` from the repo root (open `/sites/catalogue.html`). **Never `python -m http.server`** — it speaks HTTP/1.0 and drops large WebP responses under Chromium on Windows, and the catalogue page is entirely WebP (the r6 bug, `SKILL.md` Step 5 bans it by name). Everything,
images included, is committed so the whole chain of references loads from the cloud.

The contract for an entry — frontmatter keys, the nine H2 sections, origins, invariants — is
`design-catalogue/SCHEMA.md`. Categories and their meaning: `design-catalogue/categories.md`.
Anton's taste profile, read from the whole catalogue: `design-catalogue/TASTE.md`.

## Adding an entry (from the repo root)

1. `python scripts/catalogue/capture.py <url|file> <slug>` — fold, full page, lossless fold, slices.
2. `designlang <url> --wait 2000 --ignore-widgets -q -o design-catalogue/entries/<slug>/extract`
   (measured flags, from `extract_batch.py`: `--full` **hangs**, and `--screenshots --interactions` cost 269 s and 4.8 MB per site for screenshots `capture.py` already takes. Base extraction is ~61 s and still carries Motion Language, Component Anatomy and Brand Voice. For a local example site, serve it first and extract the served URL — a `file://` URL yields nothing.)
   when the page is live (motion tokens, components, typography, brand voice). Skip for images.
3. Read `shot.png` and the slices yourself, read `extract/*-design-language.md` if it exists, and write
   `entry.md` per `SCHEMA.md`. Describe relations (type weight vs air vs image vs surface vs
   motion), not a token list. Never invent a URL, a palette or a font.
4. `python scripts/catalogue/index.py` then `python scripts/catalogue/build_page.py`.
5. Commit (images too). Push only when Anton says so.

## Looking up references (Step 1b of `design`)

`python scripts/catalogue/query.py --category X --register Y --grammar Z --mode M` (all optional)
prints slugs with lane and traits. Read two to four entries in the target category as pixels
(`fold.webp`, slices) and text (their `Reference lock`), and read `TASTE.md` when the brief is
Anton's own or names no references. The page's detail panel has COPY BRIEF / COPY REFERENCE LOCK /
COPY IMAGE PROMPT for the same text.

## Photos without an API

`python scripts/catalogue/unsplash_sheet.py <out-dir> "<phrase>" ["<phrase>"...]` scrapes the
Unsplash search page, verifies each ID loads and writes a contact sheet. Shoot it, look at every
candidate, pick, then re-judge the pick under the real scrim. Vendor the winner as WebP into the
build and credit the photographer.
