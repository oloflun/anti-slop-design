# push/ — kamerans resa från kajen in i fönstret

Genererad 2026-09-06 med Higgsfield (Kling 3.0, image-to-video) från `../dusk.webp`
(Rafael Peier, Unsplash) som startbild och en genererad närbild av det tända bågfönstret
som slutbild. Orkestreraren äger materialet; byggaren ändrar det inte.

- `f001.webp` … `f100.webp`: 10 rutor/s, 10 s, 1440 px breda, i ordning. Det här är
  bildsekvensen för motorns `canvas[data-sc-sequence]` (scrub-device).
- `push-last.webp`: sista rutan, fönstret fyller ramen. Används som statisk bild under
  reduced motion och som utgångsläge för tonövergången till Hōrai-ramen.
- `push.mp4`: samma klipp som all-intra H.264 (varje ruta en keyframe), reserv för
  `video[data-sc-scrub]` om sekvensen inte kan användas.

Kredit i sidfot och NOTES: fotografen, och "rörelse genererad med Higgsfield (Kling 3.0)".
Slutmaterial: Kling 3.0 pro (1764×1176 källa), 2026-09-07. Resan slutar i det tända bågkrönta
fönstret på bottenvåningen till vänster om porten. `window-track.json` ger öppningens form per ruta.
