HTTP-inspektör för lokal utveckling

Spela in. Spela upp. Se exakt vad som ändrades.

Kvist sitter mellan din klient och API:et och spelar in varje anrop lokalt. Kör om samma sekvens mot en ny build, en annan gren eller en annan miljö. När svaret skiljer sig får du en diff i stället för en gissning.

Körs lokalt. Ingen trafik lämnar din maskin utan att du ber om det: kvist init

Request → Response · live fångst

Trafiken, som den faktiskt var

Ingen syntetisk logg. Kvist visar samma request och response som gick över nätverket, ihopkopplade och diffade mot en tidigare körning.

Request

POST /api/checkout HTTP/1.1
Host: shop.internal
Content-Type: application/json

{
  "cart_id": "c_4471",
  "coupon": "VAR25"
}

Response, diff mot förra körningen

HTTP/1.1 200 OK
Content-Type: application/json

{
  "status": "confirmed",
  "status": "pending",
  "total": 748
}

Illustrativt exempel. Ingen riktig kundtransaktion.

Kärnfunktioner

01

Spela in

Kvist lägger sig som en lokal proxy mellan din klient och API:et. Varje request och response sparas till disk i sin helhet: headers, body och timing, utan att du behöver ändra en rad kod i tjänsten själv. 

$ kvist record --port 4000
↳ 214 anrop sparade → checkout.kvist

02

Spela upp

Kör om exakt samma sekvens av anrop mot en ny build, en annan gren eller en annan miljö. Deterministiskt, utan att röra den riktiga backend-tjänsten om du inte vill. 

$ kvist replay checkout.kvist \
    --against :4001
↳ 214/214 anrop uppspelade

03

Diffa

Jämför två inspelningar rad för rad. Kvist visar exakt vilka headers, statuskoder och fält i svarskroppen som skiljer sig, inte en gissning om vad som gick sönder. 

- "status": "confirmed"
+ "status": "pending"

Terminalen är gränssnittet

Tre kommandon täcker det mesta: spela in, spela upp mot en annan miljö, och diffa två körningar mot varandra.

kvist.sh

# spela in trafik mot din lokala backend
kvist record --port 4000 --out ./traces/checkout.kvist

# spela upp samma sekvens mot en ny build
kvist replay ./traces/checkout.kvist --against http://localhost:4001

# diffa två inspelningar mot varandra
kvist diff ./traces/checkout.kvist ./traces/checkout-v2.kvist
