# Brief — Reglabok (SV)

**Verksamhet:** Reglabok är en fakturerings- och bokföringsapp riktad till svenska
enmansföretagare inom hantverksyrken (elektriker, snickare, VVS, målare). Byggd av två
tidigare hantverkare som blev utvecklare. Lanserad för åtta månader sedan, cirka 340 betalande
kunder. Appen gör: offert → faktura på plats via mobilen, automatisk momsberäkning (25/12/6 %),
export till Fortnox/Visma för de som har revisor, och ROT/RUT-avdrag ifyllt automatiskt.

**Målgrupp:** Enmansföretagare eller 2–4 anställda, hanterar idag fakturor i Excel eller ett
gammalt skrivbordsprogram, gör det ofta sent på kvällen efter jobbet. Inte tekniskt ovilliga
men har låg tolerans för krångel — appen måste vara snabbare än det gamla sättet, annars byter
de inte.

**Sidans syfte:** Landningssida för att få nya provperioder (14 dagar gratis, inget kort krävs).

**Fakta att använda (inga andra får hittas på):**
- Pris efter provperiod: 249 kr/månad, ingen bindningstid
- ROT/RUT-avdrag: ifyllt automatiskt utifrån fastighetsbeteckning, minskar felaktiga avdrag
- Momsdeklaration: exporterbar som SKV-fil, ingen inbyggd inlämning ännu (kommer, ej datum satt)
- 340 betalande kunder, ingen NPS-siffra finns, inga kundcitat är godkända att använda
- Fungerar offline och synkar när täckning finns (relevant på byggarbetsplatser)
- Kundtjänst: chatt vardagar 8–17, ingen 24/7-support

**Vad som INTE får skrivas:** påhittade kundcitat, procentsiffror på tidsbesparing utan grund,
"Sveriges bästa/mest populära", löften om momsinlämning som inte finns än.

**Leverans:** Svensk copy för hela sidan (hero, varför Reglabok, hur det funkar, pris, CTA).
Markdown: H1 för produktnamn, H2 per sektion, fetstil för lead-rader, `[Text]` för
CTA-knappar. Ingen kod, ingen HTML — ren text.
