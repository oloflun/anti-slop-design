# AB10 — designkatalogen som referenskälla i Step 1b (Tier 2 via katalogen)

Brief: Rosengrens Bokbinderi (Haga). A = SKILL.md + house-physics, Tier 3 (inga referenser). B = samma + reference-lock.md + två katalogposter (calyx, vintergatan: entry.md + shot.png lästa som bilder).

| Mått | A (utan katalog) | B (med katalog) | Not |
|---|---|---|---|
| Tier / lane | 3 · "warm archival letterpress" | 2 · "warm paper-and-thread atelier" | B:s lock namnger Vintergatan som primär, Calyx-räknare som lån |
| Hero | typ + ritad bokrygg, italic "liv" | fullbleed bokhyllefoto (verifierat ID) med typ över, italic "hålla" | båda bär gate 89-signalen (accentord i rubrik) |
| Tjänster | romerska numeraler, ledger | .01/.02/.03-ledger med högerställda noter | B tätare hierarki |
| Arbeten | fyra egna line-art-planscher | fyra hatch-platshållare märkta PLATSHÅLLARE | A vinner här; B:s ärliga platshållare är sidans svagaste yta |
| Inversion | mörk läder-sektion (adress) | mörk verkstad med foto + öppettider-ledger | B rikare |
| Spårbarhet | prosa | lock + ledger, varje drag pekar på en post | |

Visuellt (compare/fold.png, full.png lästa): B ligger närmare referensnivån (fotografisk upptakt, ledger-noter, verkstadsfoto, kolofon), A är den lugnare uppfunna världen men plattare och mer cream-default. Katalogen gjorde skillnad på pixlar där den gav något att låna (upptakten, ledgerns anatomi), och ingen skillnad där den inte gjorde det (planscherna).

**Beslut: IN.** Step 1b hämtar 2–4 katalogposter i samma familj/register före första kodraden. Modifiering: platshållare för planscher följer photo-sources.md (sök Unsplash först, hatch-ruta sist), och katalogens Brief-fält ska nämna vilka foton som faktiskt bar sidan.
