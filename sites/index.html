Audit · Registers · Proof

Six registers,
one system.

I have a hundred and thirty-seven skills installed in my Claude Code setup. Roughly thirty of them are design-related. Some are brilliant: Impeccable, taste-skill, designpowers. Others are compliance checklists. None of them, alone or composed, reliably stopped my model from shipping the same AI-generic landing page every time I asked for something premium.

The third time my model returned a centered hero stack with a chart card on the right, a four-column metric grid, three icon-title cards, and a "trusted by 10,000+ teams" line, all in Inter and all on egg-shell, I stopped fighting the model and started auditing the stack.

About twenty minutes later, in a single Opus 4.7 session, I had: a five-axis ranking of 32 design skills, one router skill at ~/.agents/skills/design/SKILL.md that fires on the trigger word design, and three landing pages built from single prompts each. None of them looked AI-generated.

Then a rebuild made the output worse, and finding out why took longer than building the thing. The second version fixed everything mechanical about the first: hooks that fired at edit boundaries instead of turn boundaries, a gate that could deny an off-brand write, telemetry that measured whether the right skill actually loaded. It never asked why the first version's output had been good. Craft that had been resident in context became a hundred and twenty files loaded on demand, the step that made you name an aesthetic before writing code disappeared, and every remaining quality gate was a prohibition. A flat, on-palette, thoroughly generic page passes all eighty-eight of those untouched.

What fixed it was separating structure from register. The three original demos are all editorial print, and treating their shared habits as universal law meant a harbour restaurant got roman numerals and a one-person software firm got a colophon. Both were worse for it. There are six registers below, one of which had no worked example to copy when it was built.

The slop ceiling.

If you've used any AI coding tool in 2026, you've seen this exact page produced for AI search startups, fintech, observability dashboards, sleep-tech wearables, B2B SaaS, dev tools, project managers, productivity suites, and CRMs.

Inter typeface. Sticky pill nav. Gradient hero text. Chart card on the right. Four-column metric grid with tiny captions. Three icon-title-body "feature" cards. Big-number row. Generic CTA. "Trusted by 10,000+ teams." Made with ❤️ in San Francisco.

Every pattern visible above is on the absolute-ban list of multiple premium design skills installed on my machine, and they didn't fire. The router this repo ships exists so this never gets shipped again. The three demos below are what fires instead, when the router is in place.

What the system shipped instead

Six single-prompt landing pages,
six registers.

Same structure underneath every one: hierarchy through scale rather than decoration, hairlines that separate where planes would not, one accent at display scale, one signature scroll piece, columns that carry their width. Everything else moves with the business. The last three were built blind by subagents in a single attempt each, with no chance to iterate.

/01
Editorial print

Calyx, Stockholm Atelier

A two-sister botanical commission studio in Vasastan, accepting eleven cuttings a week, the eleventh being a wedding. Cream + charcoal restraint, Cardo italic display, layered botanical photography. The reference target was the published floria-landing-page. Design IS the product; the page IS the brand. The job here was to keep it out of the warm-cream-with-italic-serif family that has flooded boutique-brand sites for two years. This is the register the others get wrongly pulled towards, which is why the table now names it as one option rather than the default.

Modern clean

Tidvatten, a Cold-Bath Club

A wood-fired sauna club at the end of Pier 4 in Malmö. Slate blue-grey and deep sea dark, terracotta as the only warmth, Familjen Grotesk set tight in caps. The grotesk is the point: the subject here is temperature, timetable and protocol, so precision reads truer than connoisseurship. Its set piece is the two temperatures, 2° and 85°, driving together out of blur as the section centres. The statutes are a ledger: §4, silence on the benches before seven.

Editorial print

Vintergatan, Antiquarian and Bindery

Rare books at the counter on Svartbäcksgatan in Uppsala, and behind the curtain a workshop that sews, repairs and gilds to order. /06
Historical art

Vinterspelen, Opera by Candlelight

Seventeen evenings each January in a manor theatre that closed in 1814 and then stood untouched for a hundred and thirty-four years. This was the hard test: historical art was a row in the register table with no worked example beside it, so the page had to derive the register instead of copying the nearest one on disk. It came back with period paintings in double gilt frames, gold on near-black, and captions that name inventory numbers. Every work is public domain, credited under its own frame.

The story

How it was made.

One Claude Code session. Opus 4.7 high. Roughly twenty minutes of wall-clock. The session read every design SKILL.md in batched parallel reads, scored each on a five-axis rubric (anti-slop teeth, aesthetic ceiling, execution fidelity, routing clarity, maintenance cost), demoted the compliance-checklist ones (yes, ui-ux-pro-max was one) and wrote a single master router.

The system does six things on every design task: classify the verb → pick the register from the business → name the aesthetic in one concrete phrase → source imagery before the first review → build against a craft floor that is resident, not routed → verify on pixels until a full pass finds nothing. It composes five upstream skills it did not write. All credit for taste belongs to those repos.

Two things carry the most weight, and neither is a rule about how a page should look. The first is that the exit bar is mechanical: a Stop hook blocks the session from ending while UI edits exist that nobody has looked at, so the instruction to keep going until the result beats its references does not depend on a human remembering to type it. The second is that judgement rests on pixels. Screenshots get captured and read back into context; a screenshot nobody opened does not count, and computed style is not a substitute. Both came out of a session where every check passed on a page that turned out to be visually empty.

Six demo sites validate the registers. Each from a single prompt, no build pipeline: Tailwind via CDN, Google Fonts, Chrome headless for the verification screenshots. The measuring instruments are in the repo too, and both of them were wrong on their first run in ways that would have passed a broken page. One parsed only rgb() while Tailwind 4 emits oklch(), so every colour silently became nonsense. The other measured text sitting over a photograph against the page background, which answers nothing. Suspect the measurement before you suspect your eyes.

This is the broader bet I'm working on: the rest of my stack (orchestration, memory, session continuity, ingestion, evaluation) is starting to feel like an agentic OS. Design was the last subsystem that didn't have a router. Now it does.

The Anti-Slop Design Stack

Started in a single Claude Code session, Opus 4.7 high, about twenty minutes wall-clock. Rebuilt twice since, the second time to undo what the first rebuild cost. The taste belongs to the upstreams; this repo is the layer that decides which one applies, and refuses to let a session end on work nobody looked at.
