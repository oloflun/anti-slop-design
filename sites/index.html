Audit · Router · Proof

Three sites,
one router.

I have a hundred and thirty-seven skills installed in my Claude Code setup. Roughly thirty of them are design-related. Some are brilliant — Impeccable, taste-skill, designpowers. Others are compliance checklists. None of them, alone or composed, reliably stopped my model from shipping the same AI-generic landing page every time I asked for something premium.

The third time my model returned a centered hero stack with a chart card on the right, a four-column metric grid, three icon-title cards, and a "trusted by 10,000+ teams" line — all in Inter, all on egg-shell — I stopped fighting the model and started auditing the stack.

About twenty minutes later, in a single Opus 4.7 session, I had: a five-axis ranking of 32 design skills, one master router skill at ~/.agents/skills/design/SKILL.md that fires on the trigger word design, and three landing pages built from single prompts each — every one in a different aesthetic lane, every one passing both slop tests. None of them look AI-generated.

The slop ceiling.

If you've used any AI coding tool in 2026, you've seen this exact page produced for AI search startups, fintech, observability dashboards, sleep-tech wearables, B2B SaaS, dev tools, project managers, productivity suites, and CRMs.

flowstack.app / the all-in-one platform for modern teams OPEN ↗

Inter typeface. Sticky pill nav. Gradient hero text. Chart card on the right. Four-column metric grid with tiny captions. Three icon-title-body "feature" cards. Big-number row. Generic CTA. "Trusted by 10,000+ teams." Made with ❤️ in San Francisco.

Every pattern visible above is on the absolute-ban list of multiple premium design skills installed on my machine — and they didn't fire. The router this repo ships exists so this never gets shipped again. The three demos below are what fires instead, when the router is in place.

The story

How it was made.

One Claude Code session. Opus 4.7 high. Roughly twenty minutes of wall-clock. The session read every design SKILL.md in batched parallel reads, scored each on a five-axis rubric (anti-slop teeth, aesthetic ceiling, execution fidelity, routing clarity, maintenance cost), demoted the compliance-checklist ones — yes, ui-ux-pro-max was one — and wrote a single master router.

The router does six things on every design task: detect task type → name an aesthetic lane → run both slop tests → layer the right specialist → enforce five hard bans as gates → end with impeccable polish. It composes five upstream skills it didn't write. All credit for taste belongs to those repos.

Three demo sites validated the routing. Each in a different aesthetic lane. Each from a single prompt. No build pipeline — Tailwind via CDN, Google Fonts, Chrome headless for the validation screenshots. The whole public repo fits in fifteen files.

This is the broader bet I'm working on: the rest of my stack — orchestration, memory, session continuity, ingestion, evaluation — is starting to feel like an agentic OS. Design was the last subsystem that didn't have a router. Now it does.
